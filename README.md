# Matthew Hawkins — portfolio

A static portfolio focused on IT systems, automation, and evidence from personal projects. Cream, charcoal, red, bold typography, and the illustrated portrait preserve the original identity.

## Pages

- `index.html`: professional introduction, résumé/contact actions, Shellify feature, supporting projects, anonymized backup story, and evidence-backed capabilities.
- `shellify.html`: problem, contribution, technical tradeoffs, workspace design, testing, results, limitations, and a fixed inactive-AD-user script sample generated by Shellify’s existing logic.
- `Resources/Matthew_Hawkins_Resume.pdf`: supplied résumé, unchanged and authorized for publication.

## Local review

Open `index.html` directly, or serve with `python -m http.server 4173` and visit http://localhost:4173. There is no build step or backend. Core content works without JavaScript. Preferences persist locally when storage is available; copying has a manual-selection fallback.

No PowerShell runs from this portfolio. The fixed sample contains default parameters and no workplace data. Refresh it using the intended Shellify version’s `ad-inactive` action and default values, then review the output before updating the embedded code.

## Checks

Run `node --check script.js`. For browser QA, set `PLAYWRIGHT_MODULE` to an installed Playwright module path, or install `@playwright/test` locally, then run `node tools/check-browser.cjs` from this directory. It uses Edge and file URLs, and saves screenshots under `docs/screenshots`.

See [content evidence and open items](docs/content-evidence.md) for sources and [the final polish changelog](docs/final-polish.md) for changes, confirmation items, validation, and deployment follow-up. Changes are committed locally; nothing was deployed.

For future publication, serve only the public HTML, CSS, JavaScript, images, favicon assets, manifest, and authorized résumé. Exclude the supplied brief, internal documentation, research files, and tools.
